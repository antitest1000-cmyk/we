# ToolNest

Five page static website for testing and future monetization.

Pages:
* Home
* Tools
* Weather
* Countries
* About

Public APIs:
* Open-Meteo
* REST Countries
* Quotable (quote tool, if available)

No API keys are included.

Run locally by opening index.html, or deploy the folder to a static host such as Cloudflare Pages, Netlify, Vercel, or GitHub Pages.

Replace the marked advertisement slot with an ad network's approved code only after your site is accepted by that network.
